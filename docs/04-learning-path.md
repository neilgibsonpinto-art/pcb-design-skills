# Learning Path

## General PCB Design
1. Learn basic electronics.
2. Install KiCad and design a simple board (LED blinker or Arduino shield).
3. Learn IPC basics and DFM rules.
4. Design a 4-layer board with a microcontroller.
5. Study signal integrity and high-speed design.
6. Order from a fab (JLCPCB or PCBWay), then test and debug.

## Drone and Aircraft Track
1. Learn BLDC motor fundamentals.
2. Study open-source flight controllers (Pixhawk, ArduPilot hardware).
3. Design a power distribution board.
4. Design a basic flight controller with IMU, GPS, and RC receiver.
5. Learn ESC design (gate drivers, MOSFETs, current sensing).
6. Study RF layout and EMI mitigation.
7. For aerospace careers, learn DO-254 and DO-160.
